🚀 TimeSeries Transformer API

Advanced AI-Powered Stock Price Prediction System

Built with PyTorch Transformers | Real-time Predictions | Educational Interface

📚 Student Guide: Understanding the API

This API uses transformer neural networks (similar to GPT) to predict stock prices based on historical data patterns.

🔍 What Each Endpoint Does:

  • GET /health - Checks if the API is running and which models are loaded
  • GET /model-info - Shows details about the AI model architecture and capabilities
  • POST /predict - Makes actual price predictions using the transformer model
  • POST /backtest - Tests how well the model would have performed on historical data

🎓 How to Use This Interface:

  1. Click on any endpoint below to expand it
  2. Click "Try it out" to enable the input fields
  3. Modify the example data or use the provided samples
  4. Click "Execute" to send the request
  5. View the response below - it shows what the AI predicted!

⚡ Quick Start

1 Start with /health
2 Check /model-info
3 Try a prediction!

💡 Tip: The prediction endpoint expects 60 timesteps of data with 10 features each (price, volume, etc.)
